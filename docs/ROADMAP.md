## 下一步（候选）

- **M1：双内核**——引入 OpenCode 作为可切换的第二 AI 内核（原生支持 75+ 供应商），一并增强国产模型切换体验
- **工作台 P1 增强**：图片/文件上传、Skills/MCP 管理页（引擎能力已有、UI 零入口）、语音输入
- **工作台 P2**：用量/速率显示、会话搜索与归档管理增强
- **真机兼容性专项**：收集各品牌机型反馈，优先修启动/安装兼容问题
- **镜像体积再压缩**：评估 zstd 压缩、按需可选组件（如 Python）
- **应用商店渠道**：上架酷安 / 应用宝等国内渠道（需合规与签名准备）

## 长期方向

- 工作台 UI 自维护版本（2026-09 体检后已提上日程：上游前端存在 P0 移动适配缺陷，将先以最小补丁跟进，必要时分叉自维护）
- 云盘/网页版工作台（与「零服务器」定位冲突，仅作远期评估）

## 不做（明确砍掉）

- iOS 版：本地 Linux 用户态在 iOS 上不可行
- 云端沙箱 / 托管服务：本项目零服务器，长任务跑在手机本地前台服务
- 本地模型推理：手机带不动，且违背「用线上 API」的初衷
