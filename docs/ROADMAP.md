# 路线图

> 这是项目当前的想法，随时可能调整。欢迎在 Issue 里讨论优先级。

## 已完成

- [x] M0：可安装的 APK + 设计文档（v0.1.0）
- [x] 启动流程体验优化：进度可视化、界面适配、品牌化（v0.1.1 / v0.1.2）
- [x] 解绑 OpenAI：DeepSeek / Qwen / GLM 服务商选择（v0.1.4）
- [x] 全内置、零网络安装（v0.2.0）
- [x] 构建期预组装成品镜像（v0.3.0）
- [x] API Key 加密存储 + 诊断中心（v0.3.1）
- [x] 镜像分片并行解压 + 应用瘦身（v0.4.0）

## 下一步（候选）

- **M1：双内核**——引入 OpenCode 作为可切换的第二 AI 内核（原生支持 75+ 供应商），一并增强国产模型切换体验
- **真机兼容性专项**：收集各品牌机型反馈，优先修启动/安装兼容问题
- **会话历史管理**：工作台会话的本地保存、导出、清理
- **镜像体积再压缩**：评估 zstd 压缩、按需可选组件（如 Python）
- **应用商店渠道**：上架酷安 / 应用宝等国内渠道（需合规与签名准备）

## 长期方向

- 工作台 UI 自维护版本（当前上游 codex-web-local 前端相对稳定，暂不改）
- 云盘/网页版工作台（与「零服务器」定位冲突，仅作远期评估）

## 不做（明确砍掉）

- iOS 版：本地 Linux 用户态在 iOS 上不可行
- 云端沙箱 / 托管服务：本项目零服务器，长任务跑在手机本地前台服务
- 本地模型推理：手机带不动，且违背「用线上 API」的初衷
